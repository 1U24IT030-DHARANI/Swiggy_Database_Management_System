# Swiggy Database Management System

## 📌 Project Overview

A **MySQL-based relational database** designed to manage a food delivery platform. The system handles customers, restaurants, menu items, orders, deliveries, payments, and reviews.

## 🛠️ Technologies

* MySQL
* SQL
* MySQL Workbench

## 📊 Key Features

* Customer and restaurant management
* Menu and order management
* Delivery partner tracking
* Payment management
* Customer reviews and ratings
* Primary & Foreign Keys
* Constraints and Indexing
* SQL JOIN and query operations
